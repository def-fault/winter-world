# Winter World — Frostbound

[게임 시작](https://def-fault.github.io/winter-world/)

캐릭터 선택 → 친구와 대전 → 방 만들기 → 초대 링크 공유. 친구가 참가하면 바로 시작합니다.

조작: A/D 이동, W 점프, S 방어, J/K/L 공격. 2선승제.

방장 브라우저가 전투를 진행합니다. 연결 중개는 PeerJS Cloud, 실제 데이터는 WebRTC를 사용합니다. 방장은 탭을 열어 두세요. 일부 제한된 네트워크에서는 연결되지 않을 수 있습니다.

원본 캐릭터 일러스트와 스프라이트의 권리는 원 저작자에게 있습니다. 제3자 라이브러리 PeerJS의 라이선스는 vendor/peerjs-LICENSE.txt를 참고하세요.
